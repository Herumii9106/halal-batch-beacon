# Halal Batch Beacon

"Create a modern Web3 supply chain verification dashboard called HalalTrace built for Solana blockchain tracking. Use a clean, trustworthy color palette with emerald green, slate dark blue, and white background accents.

Key Sections to Include:

Header: Navbar with logo, links (Search, Traceability, Admin Panel), and a prominent 'Connect Phantom Wallet' button with a subtle purple/green Web3 badge.

Hero Search: A prominent search card with an input field for 'Enter Product Batch Code or ID' and a 'Verify Product' button.

Verification Results Card: Show product details when verified: Product Name, Manufacturer, Certificate Number, Halal Status (Badge: Certified Halal), and Solana Transaction Signature hash link.

Supply Chain Timeline: A vertical/horizontal visual timeline showing 4 stages: Sourcing, Processing, Packaging, and Distribution with timestamps and inspector signatures.

Add Record Form (Admin): A tab/modal for producers to input new batch verification logs (Batch ID, Product Name, Halal Cert Number, Location).*

Make the interface clean, responsive, and mobile-friendly with modern card layouts and clean typography."
